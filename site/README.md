# Switchboard project page

Static site for `switchboard.octaviosantacruz.com`, built with Astro and served by
Switchboard Pages. It shares the console's identity (see `web/console/src/app.css`).

```bash
npm ci
npm run dev     # local preview
npm run build   # astro check + static build into dist/
```

Only list features under "shipped today" when they have tests and a running deployment
(`REL-008`); everything else belongs on the roadmap.
